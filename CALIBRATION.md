# Coordinate Calibration (in-app, no ADB)

From the RobotRun bubble, open the expanded control panel and choose **Capture Calibration (Bot stopped)**. Stop the bot first but leave Screen Capture / MediaProjection running. RobotRun hides its entire bubble and any existing calibration window, waits 500 ms, then acquires a strictly newer normalized frame from LatestFrameProvider; frames captured before the hide or more than one second old are rejected. On timeout, it restores the UI (or shows the previous snapshot for a failed recapture). No Accessibility taps are sent to the game.

The still image is the same 1280x720 frame and contentRect used by StateDetector. Tap to select a point; drag to pan and pinch or use +/- to zoom. The UI shows logical X/Y and corresponding physical X/Y **for that capture's exact contentRect**, not a universal Redfinger offset. Enter a short point name (for example POST_RELAY_1, POST_RELAY_2, POST_RELAY_3, TIME_DEAL, PARTY_RUN_SEASON_REWARDS), save to private `calibration_points` preferences, load a saved point by name, or export a marked PNG to Pictures/CookieRunBot/calibration. Captures remain in memory unless exported.

Saved points are reference notes only: the tool never changes AutomationConfig, enabled handlers, thresholds, state detection, or the Redfinger uncalibrated-action safety block. Recalibrate when display geometry/cutout changes. A 2400x1080 full-screen physical point outside the contentRect cannot be represented by the normalized image. The UI intentionally refuses calibration while BotRuntime is running to prevent automation from changing the screenshot between hiding the overlay and capture.
